# 🩺 Dr. Nurjahan (Mukti) - Medical Portfolio & Appointment Booking System

A modern, full-stack medical portfolio and online appointment booking web application built for **Dr. Nurjahan (Mukti)**, a specialist in Gynecology and Obstetrics.

🌐 **Live Website:** [www.drnurjahanmukti.com](https://www.drnurjahanmukti.com/)

---

## ✨ Key Features

- **Dynamic Navigation & Hero Section:** Responsive navbar with smooth scrolling and a clean, patient-friendly hero section.
- **Chamber & Schedule Directory:** Detailed information about hospital/clinic chambers, visiting hours, and locations.
- **Online Appointment Booking:** Interactive appointment booking form integrated with a backend API to store patient bookings directly in MongoDB.
- **Responsive UI/UX:** Built with modern typography (`Plus Jakarta Sans`) and styled for seamless viewing across mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack

**Frontend:**
- React.js & TypeScript
- Vite
- CSS3 / Tailwind CSS
- Lucide React / FontAwesome Icons

**Backend:**
- Node.js & Express.js
- MongoDB & Mongoose (Database for Appointment Bookings)
- RESTful API

**Deployment:**
- Namecheap Shared Hosting (cPanel)
